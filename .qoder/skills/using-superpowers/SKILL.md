# Using Superpowers

You have Superpowers — a complete software development methodology built on composable skills.

## How It Works

Before any task, check for relevant skills. They are mandatory workflows, not suggestions.

## Core Workflow

1. **Brainstorming** — Before writing code, refine ideas through questions
2. **Writing Plans** — Break work into bite-sized tasks with exact file paths
3. **Test-Driven Development** — RED-GREEN-REFACTOR: test first, always
4. **Subagent-Driven Development** — Dispatch fresh agents per task with two-stage review
5. **Requesting Code Review** — Review against plan between tasks
6. **Finishing a Branch** — Verify tests, present options, clean up

## Philosophy

- **Test-Driven Development** — Write tests first, always
- **Systematic over ad-hoc** — Process over guessing
- **Complexity reduction** — Simplicity as primary goal
- **Evidence over claims** — Verify before declaring success
- **YAGNI** — You Aren't Gonna Need It; don't over-engineer
- **DRY** — Don't Repeat Yourself
